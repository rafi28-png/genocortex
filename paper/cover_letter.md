To the Editors,

Dear Editor,

Please consider our manuscript, **"The Fractal Predictive Cortex: a training-free,
alignment-free, self-organising model that unifies prediction, anomaly detection,
classification, and phylogenetics for biological sequences,"** for publication as
a methods / application note in *[Journal]*.

Alignment-free sequence analysis is powerful but fragmented: each task
(compression, classification, distance estimation, anomaly detection) is served
by a separate tool with its own hyperparameters, most importantly the k-mer word
length *k*. We ask whether a single model can answer all of these questions from
one internal signal, and present the Fractal Predictive Cortex (FPC): a
self-organising model that grows predictive "prototypes" in Chaos Game
Representation space specifically where its next-symbol prediction is most
*surprised*, and derives all four capabilities from that one surprise signal —
with no training labels, no alignment, no pretrained weights, and no fixed *k*.

We wish to be explicit about the nature of the contribution. A systematic,
adversarially-verified literature review (reported in §1.1) establishes that every
individual ingredient of FPC has prior art; the contribution is their
**unification** — surprise-driven growing memory in CGR space serving four tasks
from one objective — for which we find no near-identical precedent. Consistent
with the AFproject benchmarking study, we make **no claim of universal
superiority**: we report, plainly, both the tasks where FPC matches strong
standard tools (it ties Mash and FFP on a real mammalian-mitogenome Robinson–
Foulds benchmark, and is statistically indistinguishable from them across 25
controlled phylogenies) and the tasks where it is beaten (composition methods win
on deep-divergence viral families; a matched Markov model wins on Markov-generated
compression). We believe this honest, fully-reproducible framing — every number
and figure regenerated by open-source code that depends only on NumPy and SciPy —
is exactly what a methods contribution should offer.

This work is original, not under consideration elsewhere, and all authors approve
the submission. We declare no competing interests. Code and data are openly
available (see Data and Code Availability).
